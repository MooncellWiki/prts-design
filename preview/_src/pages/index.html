PRTS.WIKI · NEW SKIN DESIGN SYSTEM

AKDS明日方舟网页设计系统

以明日方舟官网与游戏内 UI 为视觉母体，按令牌—组件—模式分层，为 prts.wiki 的 MediaWiki 皮肤定义色彩、字体、间距、装饰语言与组件库。所有颜色均可追溯至官网 CSS、游戏解包精灵或 gamedata。

这是一份「活」的设计规范
本页本身运行在皮肤骨架之上：页眉、侧栏、页面标签、右侧目录、页脚均为最终皮肤的组件。右上角可切换 终端模式（暗） / 档案模式（亮） / 跟随系统 —— 两套主题均取材于游戏内的双色 UI 世界。

设计理念 Philosophy

方舟本体的关键词：纯黑与纯白的对撞、青蓝强调、直角、拉丁大写字、白色线稿图标、半调网点与斜纹。UI 是「档案 / 终端」而不是「驾驶舱」。

01 · Monochrome first黑白为体，青为用

大面积黑/白/灰承载信息，青色 #18D1FF（官网）/ #0098DC（游戏内）只用于选中、链接、强调条与主要动作；黄色 #FFD800 为次强调（稀有度、提示）。

02 · Square, not rounded直角，没有斜边

圆角为 0，也不做切角 / 斜切 / 斜带；层级与状态靠色条、黑白反转、角标三角表达。色条与细框用 border-image 直角拼接，不让 border 在角上斜接出斜边。

03 · Latin display大写拉丁字作装饰层

Novecento Sans Wide / Bender / Oswald 只用于标题旁的英文、编号、数值与水印；中文正文一律思源黑体，保证维基长文可读性。

04 · Two canonical themes终端 / 档案 双主题

游戏本身就是双色世界：主界面/作战为黑，干员档案/商店为白灰。两套主题都是「正典」，用 MW 1.43 的 clientPrefs 机制切换。

05 · Wiki-native先服务内容，再谈风格

wikitable、TOC、引用、图库、TabberNeue、Cargo 表都在设计范围内；组件用纯 CSS 类表达，可直接写进模板与 TemplateStyles。

06 · Traceable tokens每个颜色都有出处

令牌注释标明来源：官网 CSS、解包精灵采样、gamedata 富文本样式表 / 稀有度色表。避免"看起来像"的近似。

DO
  • 标题左侧粗色条 + 短横条
  • 色条 / 黑白反转 / 角标三角表示选中与层级
  • HUD 级数值 / 编号 / 大写小标签用 Bender（粗体或大字号、独立出现）；表格与正文里的连续数字用正文字体 + 等宽数字
  • 白色线稿图标在亮色主题下 filter: invert(1)
  • 只在选中/主动作/链接使用青色
  • 斜纹表示危险、施工、禁用
DON'T
  • 圆角卡片、阴影堆叠、玻璃拟态
  • 切角、平行四边形、斜带、斜接出来的小斜边
  • 菱形项目符号、辉光文字
  • 用金黄 #FFD429 做主强调色
  • 大写英文替代中文标题
  • 正文用 Orbitron/等宽
  • 稀有度用非官方色阶

装饰语言 Decoration primitives

方舟界面的"签名"不是某个组件，而是一组可叠加的几何装饰。它们全部是纯 CSS 类，可以叠在任何盒子上。

色条 + 细框 · 直角拼接
色条是 border-left，框是 border-image
pre / 消息 / 面板头 / 模组卡 同一做法

粗 border-left 遇上 1px 的 border-top/bottom 会被浏览器斜接出一道小斜边；系统里没有斜边，所以框用 border-image 画（tokens.css §Shape）。
